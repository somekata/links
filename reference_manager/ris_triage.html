1. Zotero などから .ris ファイルをダウンロードする

Zotero の場合
書誌情報をエクスポートしたいコレクション（またはライブラリ全体）を右クリック → Export Collection...（またはExport Library...）を選択 → 形式（Format）で RIS を選び、Export をクリックしてください。
複数のコレクションを別々に書き出した場合は、複数の .ris ファイルができますが、このツールは複数ファイルを一度にまとめて読み込めます。
EndNote / Mendeley など他の文献管理ツールの場合
多くの文献管理ソフトは "Export" メニューから RIS 形式を選択できます。PubMedやGoogle Scholarから直接RISをダウンロードできる場合もあります。

2. このツールに読み込む

「Triage」タブに戻り、+ Import .ris file(s) ボタンをクリックして、ダウンロードした .ris ファイルを選択してください（複数選択可）。 表に First Author / Journal / Year が一覧表示されます。

3. 絞り込み・並び替え

  • 検索ボックスで著者名・雑誌名・年・タイトルを横断的にフィルターできます
  • 列見出し（First Author / Journal / Year / Priority）をクリックするとソートされます
  • 行をクリックすると、タイトル・著者全員・Abstract・DOIリンクを含む詳細が表示されます

4. 優先度をつける

  • 各行の Priority 列は1〜5の5段階（数字が大きいほど優先度が高い、デフォルト3）
  • 複数の論文をチェックすると画面下に一括操作バーが現れ、1〜5のボタンで優先度をまとめて設定できます

5. 書き出す

  • Export CSV：チェックした論文をCSV形式でダウンロード
  • Export PDF：チェックした論文を優先度の高い順に並べ、First Author, Journal, Year, Priority のあとにタイトルとAbstractが続く形式で出力
