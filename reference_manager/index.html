PubMed → RIS 変換ツール

PubMed形式のテキストを RIS 形式に変換します（EndNote / Zotero / Mendeley 等で読み込み可能）。
ツールを開く →

使い方

  1. PubMedで文献を検索し、対象を選択（またはページ全体）した状態で Send to → Citation manager、あるいは Format: PubMed を選んでテキストをダウンロード（.txt / .nbib）。
  2. このツールを開き、左側のテキストボックスにその内容を貼り付けるか、「ファイルを選択」で直接読み込む。
  3. 「RISに変換」をクリックすると右側に変換結果が表示される。複数件のレコードもまとめて変換可能。
  4. 「.risをダウンロード」で .ris ファイルとして保存。そのまま ris_triage.html に読み込める。

Reference Triage（文献トリアージ）

複数の .ris ファイルを取り込み、検索・並び替え・優先度付けをしたうえで CSV / HTML / PDF に書き出します。
ツールを開く →

使い方

  1. + Import .ris file(s) から .ris ファイルを読み込む（複数選択可）。Zotero等からのエクスポート、または上の pubmed_to_ris.html で変換したファイルが使える。
  2. 検索ボックスや年・優先度のフィルターで絞り込み、列見出しクリックで並び替え。行をクリックするとタイトル・著者全員・Abstract・DOIリンクを表示。
  3. 各行のPriority列（1〜5、デフォルト3）で優先度を設定。複数選択して一括操作バーからまとめて設定することも可能。
  4. チェックした文献を Export CSV / Export HTML / Export PDF のいずれかで書き出す（PDFは優先度の高い順）。

ファイルの読み込み・処理はすべてブラウザ内で完結し、外部サーバーへの送信は行われません（ツール内の「使い方」タブにも詳細あり）。
