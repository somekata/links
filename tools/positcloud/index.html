このガイドでできるようになること

① 環境を準備Posit Cloudに登録し、RStudioを起動する
② プロジェクトを作る解析ごとに作業場所を分ける

最初のポイント：Posit Cloudは「Rそのもの」ではなく、クラウド上でRStudioやJupyterを使うサービスです。ここでは医学・生命科学の統計解析で使いやすいRStudio Projectを扱います。

1Posit Cloudとは

Posit Cloudは、WebブラウザからRStudio IDEを利用できるクラウドサービスです。自分のPCにRやRStudioをインストールしなくても、ログインしてプロジェクトを開けばRの解析を始められます。

用語意味
Workspace自分の作業を一覧・管理する場所
Project解析ごとの作業単位。コード、データ、パッケージなどをまとめる
RStudio IDEコードを書き、実行し、結果を確認する画面
プロジェクトごとに環境が分かれます。「授業の演習」「論文Aの解析」「グラフ作成」など、目的ごとにProjectを作ると整理しやすくなります。

2URLを開いてアカウントを取得

まず公式サイトにアクセスします。

Posit Cloudを開く ↗ 公式スタートガイド ↗
  1. トップページで「Get Started」または「Sign Up」を選択。 すでにアカウントがあれば「Log In」。
  2. 登録方法を選ぶ。 画面に表示されるメールアドレス等の登録項目、または利用可能な外部アカウント認証に従います。
  3. メール認証が求められた場合は、受信メールの案内に従う。
  4. ログイン後、Workspaceを開く。 ここが自分のプロジェクトを管理する場所です。
料金・利用枠：無料プランが用意されていますが、利用できる計算時間・メモリ・機能などはプランや時期によって異なります。授業や研究で継続利用する場合は、登録時に表示される最新のプラン条件を確認してください。

3新しいプロジェクトを作る

  1. Workspace画面で 「New Project」 をクリック。
  2. メニューから 「New RStudio Project」 を選択。
  3. 起動を待つと、ブラウザ内にRStudio IDEが表示されます。
  4. 画面上部の 「Untitled Project」 などのプロジェクト名をクリックし、内容が分かる名前に変更します。

例：m3_bacteriology_practice、amr_analysis_2026、lecture_r_basics

プロジェクト名は英数字とアンダースコアを使うと、ファイル名やコードとの相性がよく、管理もしやすくなります。

プロジェクトの中身（例）

m3_bacteriology_practice/
├── m3_bacteriology_practice.Rproj
├── analysis.R
├── data/
│   └── sample_data.csv
└── output/
    └── figure1.png

これは整理例です。最初からフォルダが全部作られているわけではありません。必要に応じてFilesペインから作成します。

4RStudio画面の見方

標準的なRStudio画面は、主に4つの領域で構成されています。

Source（左上）Rスクリプトを書く場所。コードを保存して何度も実行できる。
Console（左下）Rの命令を直接実行する場所。実行結果やエラーも表示される。
Environment / History（右上）作成したデータや変数、実行履歴を確認する。
Files / Plots / Packages / Help（右下）ファイル一覧、グラフ、パッケージ、ヘルプなどを確認する。

最初に覚える操作

操作方法
新しいRスクリプトFile → New File → R Script（Windows/Linux：Ctrl+Shift+N）
スクリプトを保存Ctrl+S
カーソル行を実行Ctrl+Enter
複数行を実行範囲を選択して Ctrl+Enter
全コードを実行Sourceペインの「Source」ボタン

MacではショートカットのCtrlがCommandになる場合があります。ブラウザやOSの設定によって異なることがあります。

5コードを書く・保存する

  1. File → New File → R Scriptを選択。
  2. 左上のSourceペインにコードを書く。
  3. Ctrl+Sで、例えば analysis.R として保存。
  4. 実行したい行にカーソルを置き、Ctrl+Enter。
  5. 結果はConsole、グラフはPlotsペインで確認。

まずは計算してみる

# はじめてのRコード
2 + 3

# 変数に値を入れる
bacteria_count <- 120
bacteria_count * 2

# ベクトル（複数の値）
growth <- c(0.2, 0.5, 0.7, 0.9, 1.1)
mean(growth)   # 平均
sd(growth)     # 標準偏差

<- は「代入」を表します。#より右側はコメントなので、実行されません。

パッケージを使う

パッケージはRの機能を追加する部品です。初回にインストールし、その後のセッションで読み込みます。

# 初回だけ実行（未インストールの場合）
install.packages("ggplot2")

# 解析を始めるたびに実行
library(ggplot2)
インストールには通信・計算時間がかかることがあります。同じパッケージを毎回インストールする必要はありません。エラーが出たら、まずパッケージ名の綴りとConsoleのメッセージを確認します。

6実習：ダミーデータを解析する

CSVファイルを用意しなくても、Rコードだけで練習できます。3群の測定値を作り、平均・標準偏差を計算して箱ひげ図を描きます。

① データを作る

# 3群×各10例のダミーデータ
df <- data.frame(
  group = rep(c("対照群", "治療群A", "治療群B"), each = 10),
  value = c(
    8, 9, 10, 10, 11, 12, 9, 10, 13, 8,
    5, 6, 7, 8, 7, 9, 6, 8, 7, 6,
    3, 4, 5, 6, 4, 5, 7, 4, 6, 5
  )
)

# データの先頭と構造を確認
head(df)
str(df)

② 群ごとの要約統計量を出す

# 群ごとの平均と標準偏差
aggregate(value ~ group, data = df, FUN = mean)
aggregate(value ~ group, data = df, FUN = sd)

# まとめて表示する方法
result <- aggregate(
  value ~ group,
  data = df,
  FUN = function(x) c(n = length(x),
                      mean = mean(x),
                      sd = sd(x))
)
result

③ 箱ひげ図を描く

# 基本機能だけで描く（追加パッケージ不要）
boxplot(
  value ~ group,
  data = df,
  col = c("#8ECAE6", "#90BE6D", "#F4A261"),
  ylab = "測定値",
  xlab = "群",
  main = "3群の測定値"
)
実習のゴール：Consoleに要約結果が表示され、Plotsペインに3群の箱ひげ図が出れば成功です。コードを少し変えて、値や群名を変えてみましょう。

7手元のCSVファイルを読み込む

① CSVをアップロード

  1. RStudio右下の Files タブを開く。
  2. 必要なら New Folder で data フォルダを作る。
  3. data フォルダを開き、Upload をクリック。
  4. PC内のCSVファイルを選択してアップロード。

② Rで読み込む

# dataフォルダ内のsample_data.csvを読む
dat <- read.csv(
  "data/sample_data.csv",
  header = TRUE,
  fileEncoding = "UTF-8"
)

# 読み込めたか確認
head(dat)
str(dat)
summary(dat)

文字化けする場合は、CSVの文字コードを確認してください。WindowsのExcelから保存したCSVでは、環境によって fileEncoding = "CP932" が必要なことがあります。

重要：CSVの列名に合わせてコードを変更します。例えば列名が group と value なら boxplot(value ~ group, data = dat) のように解析できます。

③ 作業フォルダを確認する

getwd()       # 現在の作業フォルダ
list.files()  # ファイル一覧
list.files("data")

8保存・再開・共有

  • コード：Rスクリプトを Ctrl+S で保存します。
  • データ：アップロードしたファイルはプロジェクト内に置きます。
  • 再開：次回ログイン後、Workspaceから該当プロジェクトを開きます。
  • バックアップ：プロジェクトのメニューにあるExportから、プロジェクト一式をZIPとしてダウンロードできます。
  • 共有：Project SettingsのAccessで共有範囲を設定します。共有対象や権限を必ず確認してください。
共有時の注意：「All Posit Cloud Users」など広いアクセス範囲にすると、リンクを知る他の利用者が閲覧・コピーできる場合があります。個人情報や未公開データを含むプロジェクトは共有設定を慎重に確認してください。

9よくあるつまずき

困ったことまず確認すること
コードを実行できないSourceペインにカーソルがあるか、行を選択してCtrl+Enterを押したか確認。
object not foundその変数を作るコードを先に実行したか、名前の大文字・小文字や綴りを確認。
cannot open fileファイルをアップロードしたか、パスとファイル名が正しいか、getwd()で作業場所を確認。
パッケージがないinstall.packages()でインストール後、library()で読み込む。
画面が止まったように見える重い処理やパッケージのインストール中か確認。必要なら処理終了を待つ。
利用枠・時間の警告が出るアカウントのプランと利用状況を確認。不要なプロジェクトやセッションを整理。
