開始する前に、このツールの内容と使い方をご確認ください。

このツールについて

CRE（カルバペネム耐性腸内細菌目細菌）として検出された菌について、感受性パターンからCPE（カルバペネマーゼ産生菌）およびMBL（メタロβラクタマーゼ）産生の「疑い度」を参考値として段階的に確認できる教育用の試作ツールです。臨床微生物検査・感染症診療に関わる方の学習やディスカッションを想定しています。

構成（4ステップ）

  1. カルバペネムスクリーニング：メロペネム/イミペネムMIC、またはエルタペネムの結果からCPE疑い度を推定します。
  2. 既存のβ-ラクタムからの推測：アズトレオナムなど従来からの検査項目の感受性パターンから、ESBL/AmpC共産生の有無やおおまかな傾向の手がかりを確認します。
  3. 確認検査：mCIM/eCIM、Carba NP、CDT、分子検査などの確認検査の選び方と、結果を反映した場合の疑い度の変化を確認します。
  4. 直接感受性（新規β-ラクタム薬）：セフタジジム/アビバクタム等、新規配合剤への感受性パターンからMBL疑い度を推定します。

使い方

  1. ステップ1で該当する項目を選択し、「判定する」を押します（どちらか一方の入力でも判定できます）。
  2. 判定するとステップ2〜4が解放されます。実施した検査があれば、任意で追加入力してください。
  3. 各ステップの「反映する」「計算する」ボタンで、参考値の更新を確認できます。
  4. 「リセット」を押すといつでも最初からやり直せます。

        耐性機序の解説

        新規β-ラクタム系薬の使い分け

        カルバペネマーゼのクラスによって有効性が大きく異なり、特にMBL（NDM・VIM・IMP）に対してはセフィデロコルを除き実質的に無効という点が最大の使い分けのポイントです。

        mCIM/eCIM等でカルバペネマーゼ産生が確認され、分子検査等でクラスが判明した時点で、この対応表に従って選択薬を絞り込む運用が現実的です。MBL産生が疑われる、または確認された場合は、単剤のCAZ/AVIやIPM/RELは避け、セフィデロコル単剤、あるいはアズトレオナム＋CAZ/AVIなどの併用療法を検討する必要があります。
