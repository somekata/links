Theme

      
A theme is a collection of flag sets. A flag is a label plus keywords; a record gets the flag when a keyword appears in the PubMed fields you tick for that set. Build the sets below, then say which sets form the axes of figures B and C. Everything is applied to the MAIN tab as you type.

      

      
Quick start: load your PubMed file, then press this button. Common specimens, methods, populations and study designs found in the file, plus its most frequent MeSH terms and keywords, are proposed as ticked flags. Untick what you do not need.

      

      

      

    


    

      
1. Flag sets

      
Keywords: separate with commas. A plain word matches the whole word, pulmon* matches a prefix, *fung* matches anywhere, "cystic fibrosis, adult" keeps a comma inside a phrase, /regex/ is a raw regular expression. The number at the right of each flag is how many loaded records it matches; a red 0 means nothing matched.

What the page does

      
Each record is read from the MEDLINE-format file and sorted by fixed regular expressions applied to the publication type, title, abstract, keywords and MeSH terms. The same input always gives the same output, and no AI is involved at run time. The rules are listed under Show classification rules on the MAIN tab.

      
The file is processed only in your browser and is never uploaded. PubMed exports up to 10,000 records per file.

    


    

      
Limits

      
Classification uses words, not full texts, so some records will be misclassified (for example, the border between clinical and basic studies, and research letters labelled as letters). Counts in the disease-by-specimen map are not exclusive. Check any number against the source records before relying on it.
