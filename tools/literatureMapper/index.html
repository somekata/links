Mycobiome Literature Mapper

Load a PubMed export in MEDLINE format. The page classifies each record with fixed, rule-based regular expressions (no AI) and draws year-by-study-type, disease-by-specimen, method, country, journal, author, MeSH, keyword, fungal-genus, gap-map, cumulative-growth, Sankey and alluvial summaries, and on the TABLE tab a disease-by-disease summary table (specimens, methods, main fungi, key findings, limitations) with a study list. Files are processed only in this browser and are never uploaded.

What the page does

      
Each record is read from the MEDLINE-format file and sorted by fixed regular expressions applied to the publication type, title, abstract, keywords and MeSH terms. The same input always gives the same output, and no AI is involved at run time. The rules are listed under Show classification rules on the MAIN tab.

      
The file is processed only in your browser and is never uploaded. PubMed exports up to 10,000 records per file.

    


    

      
Limits

      
Classification uses words, not full texts, so some records will be misclassified (for example, the border between clinical and basic studies, and research letters labelled as letters). Counts in the disease-by-specimen map are not exclusive. Check any number against the source records before relying on it.
