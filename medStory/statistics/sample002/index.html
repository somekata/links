群間比較の解析・作図サンプル（蛍光強度・菌数）

A, B, C の 3 群を比較するデータ 2 種類と、R（tidyverse）での解析・作図コード、見た目を変えるためのヒントです。

sample002a 蛍光強度 sample002b 菌数 (CFU/mL) 見た目を変えるヒント 注意点

使い方

  1. CSV を R の作業ディレクトリ（スクリプトと同じフォルダ）に保存します。
  2. コードは [1/4] → [4/4] の順に上から実行します（各ブロックのコピー、または 4 つまとめてコピー）。
  3. 必要なパッケージは tidyverse のみです。未導入なら install.packages("tidyverse") を実行します。

CSV は人間が入力しやすいワイド型（列 = 群、行 = 反復）です。コード内で pivot_longer() によりロング型に変換します。

（上から順に実行する一続きのスクリプトです）

[1/4] 読み込み・整形・統計解析（002a）
# ============================================================
# sample002a : 蛍光強度の3群比較 (n = 10)
# [1/4] 読み込み・整形・統計解析
# ============================================================
library(tidyverse)

# --- 1. 読み込み（ワイド型）→ ロング型へ変換 ---------------
df_wide <- read_csv("sample002a.csv")

df <- df_wide %>%
  pivot_longer(everything(), names_to = "Group", values_to = "Fluorescence") %>%
  mutate(Group = factor(Group, levels = c("A", "B", "C")))

# --- 2. 記述統計（平均・SD） --------------------------------
df_summary <- df %>%
  group_by(Group) %>%
  summarise(
    n    = n(),
    Mean = mean(Fluorescence),
    SD   = sd(Fluorescence),
    .groups = "drop"
  )
print(df_summary)

# --- 3. 前提条件の確認 --------------------------------------
# 群ごとの正規性（Shapiro-Wilk）: p > 0.05 なら正規性を棄却できない
df %>%
  group_by(Group) %>%
  summarise(p_shapiro = shapiro.test(Fluorescence)$p.value, .groups = "drop") %>%
  print()

# 等分散性（Bartlett 検定）: p > 0.05 なら等分散を棄却できない
bartlett.test(Fluorescence ~ Group, data = df)

# --- 4. 一元配置分散分析（ANOVA） ---------------------------
fit <- aov(Fluorescence ~ Group, data = df)
summary(fit)

# --- 5. 多重比較 --------------------------------------------
# (a) Tukey HSD（ANOVA の事後検定）
TukeyHSD(fit)

# (b) 補正付き t 検定（Welch の t 検定 + Holm 補正）
pw <- pairwise.t.test(
  df$Fluorescence, df$Group,
  p.adjust.method = "holm",   # "bonferroni", "BH", "none" なども可
  pool.sd = FALSE             # FALSE: Welch の t 検定 / TRUE: 全群の SD をプール
)
print(pw)

# --- 6. 図に載せる p 値の表を作る（有意差ブラケット用） -----
top  <- max(df$Fluorescence)   # データの最大値
step <- 0.10 * top             # ブラケットを積む間隔

p_df <- as.data.frame(as.table(pw$p.value)) %>%
  filter(!is.na(Freq)) %>%
  transmute(group1 = as.character(Var2),
            group2 = as.character(Var1),
            p_adj  = Freq) %>%
  mutate(
    label = case_when(
      p_adj < 0.001 ~ "***",
      p_adj < 0.01  ~ "**",
      p_adj < 0.05  ~ "*",
      TRUE          ~ "ns"
    ),
    xmin = match(group1, levels(df$Group)),
    xmax = match(group2, levels(df$Group))
  ) %>%
  arrange(xmax - xmin, xmin) %>%                  # 近い群のペアを下に積む
  mutate(y.position = top + step * row_number())
print(p_df)

# 有意差ブラケットを描く関数（p_df の内容に従って線と記号を重ねる）
add_brackets <- function(d, tick = 0.3 * step, text_size = 5, line_size = 0.5) {
  list(
    # 横線
    geom_segment(data = d,
                 aes(x = xmin, xend = xmax, y = y.position, yend = y.position),
                 inherit.aes = FALSE, linewidth = line_size),
    # 左右の短い縦線
    geom_segment(data = d,
                 aes(x = xmin, xend = xmin, y = y.position, yend = y.position - tick),
                 inherit.aes = FALSE, linewidth = line_size),
    geom_segment(data = d,
                 aes(x = xmax, xend = xmax, y = y.position, yend = y.position - tick),
                 inherit.aes = FALSE, linewidth = line_size),
    # 記号（*, **, ***, ns）
    geom_text(data = d,
              aes(x = (xmin + xmax) / 2, y = y.position, label = label),
              inherit.aes = FALSE, vjust = -0.3, size = text_size)
  )
}

2. sample002b：菌数（CFU/mL）の 3 群比較（n = 5、log10 変換して解析）

sample002b.csv をダウンロード

  • 群: A = コントロール（109 前後）、B = 治療群（106〜107 前後）、C = 治療群（103〜105 前後）。各 n = 5
  • 値: CFU/mL（科学表記）。菌数は桁で変動するため、log10() で変換した値で解析・作図します
  • 解析: log10 値の記述統計（幾何平均も算出）→ 前提の確認 → ANOVA と Welch の ANOVA → Tukey HSD、Welch の t 検定 + Holm 補正

このサンプルでは Bartlett 検定が p = 0.013 となり、群間で分散が異なります（C 群のばらつきが大きい）。Tukey HSD は等分散を仮定するため、等分散を仮定しない Welch の ANOVA と、Welch の t 検定 + Holm 補正を併記しています。図の p 値には後者を使っています。

[1/4] 読み込み・log10 変換・統計解析（002b）
# ============================================================
# sample002b : 菌数（CFU/mL）の3群比較 (n = 5)  ※ log10 変換して解析
# [1/4] 読み込み・log10 変換・統計解析
# ============================================================
library(tidyverse)

# --- 1. 読み込み（ワイド型）→ ロング型へ変換 → log10 変換 ---
df_wide <- read_csv("sample002b.csv")

df <- df_wide %>%
  pivot_longer(everything(), names_to = "Group", values_to = "CFU") %>%
  mutate(
    Group  = factor(Group, levels = c("A", "B", "C")),
    logCFU = log10(CFU)     # 常用対数に変換。以降の解析・作図はこの列を使う
  )
# 注意: CFU が 0 の検体があると log10(0) = -Inf になる。
#       検出限界の値（または 1/2）で置き換える、log10(CFU + 1) を使う、などで対処する。

# --- 2. 記述統計（log10 値の平均・SD） ----------------------
df_summary <- df %>%
  group_by(Group) %>%
  summarise(
    n       = n(),
    Mean    = mean(logCFU),     # log10 値の平均
    SD      = sd(logCFU),       # log10 値の SD
    GeoMean = 10^Mean,          # 幾何平均 (CFU/mL) = 10^(log10 値の平均)
    .groups = "drop"
  )
print(df_summary)

# --- 3. 前提条件の確認（log10 値で行う） --------------------
# 群ごとの正規性（Shapiro-Wilk）。n = 5 では検出力が低い点に注意
df %>%
  group_by(Group) %>%
  summarise(p_shapiro = shapiro.test(logCFU)$p.value, .groups = "drop") %>%
  print()

# 等分散性（Bartlett 検定）: p > 0.05 なら等分散を棄却できない
bartlett.test(logCFU ~ Group, data = df)

# --- 4. 一元配置分散分析（log10 値） ------------------------
fit <- aov(logCFU ~ Group, data = df)
summary(fit)

# 群間で分散が大きく異なる場合は Welch の ANOVA（等分散を仮定しない）
oneway.test(logCFU ~ Group, data = df, var.equal = FALSE)

# --- 5. 多重比較 --------------------------------------------
# (a) Tukey HSD（等分散を仮定した事後検定）
TukeyHSD(fit)

# (b) 補正付き t 検定（Welch の t 検定 + Holm 補正）
pw <- pairwise.t.test(
  df$logCFU, df$Group,
  p.adjust.method = "holm",   # "bonferroni", "BH", "none" なども可
  pool.sd = FALSE             # FALSE: Welch の t 検定 / TRUE: 全群の SD をプール
)
print(pw)

# --- 6. 図に載せる p 値の表を作る（有意差ブラケット用） -----
top  <- max(df$logCFU)         # log10 値の最大値
step <- 0.08 * top             # ブラケットを積む間隔

p_df <- as.data.frame(as.table(pw$p.value)) %>%
  filter(!is.na(Freq)) %>%
  transmute(group1 = as.character(Var2),
            group2 = as.character(Var1),
            p_adj  = Freq) %>%
  mutate(
    label = case_when(
      p_adj < 0.001 ~ "***",
      p_adj < 0.01  ~ "**",
      p_adj < 0.05  ~ "*",
      TRUE          ~ "ns"
    ),
    xmin = match(group1, levels(df$Group)),
    xmax = match(group2, levels(df$Group))
  ) %>%
  arrange(xmax - xmin, xmin) %>%                  # 近い群のペアを下に積む
  mutate(y.position = top + step * row_number())
print(p_df)

4. 注意点

  • 検定の選び方: ANOVA 後の Tukey HSD と、補正付き t 検定のどちらを使うかは、データを見る前に決めておきます。結果を見て有意になる方を選ぶことは避けてください。
  • 小さい n: n = 5〜10 では Shapiro-Wilk 検定の検出力は低く、「p > 0.05」でも正規性が保証されるわけではありません。散布図 + 箱ひげ図で分布を必ず確認します。
  • 棒グラフ: 棒グラフは個々のデータの分布を隠すため、散布図 + 箱ひげ図の併用（または 3-4 の点の重ね描き）を推奨します。図の説明文には、エラーバーが SD か SEM か、n はいくつかを明記してください。
  • log10 値の SD: 002b の SD は log10 値の SD です。CFU/mL に戻した「平均 ± SD」ではありません。CFU/mL で代表値を示すなら幾何平均（GeoMean）を使います。
  • CFU が 0 の検体: log10(0) は -Inf になります。検出限界の値（または 1/2）に置き換える、log10(CFU + 1) を使う、などの方針を決めて報告します。
  • 学名の表記: 属名・種名はイタリック（Escherichia coli）、血清型はイタリックにしません（Salmonella Typhi）。
  • 動作確認: R 4.3.3 / ggplot2 3.4.4 / tidyverse 2.0.0 で動作確認しています。linewidth は ggplot2 3.4.0 以降の引数です（古い版では size）。
  • データ: 本ページの CSV は、実験を想定して作成した架空のサンプルデータです。
