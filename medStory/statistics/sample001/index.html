細菌増殖曲線サンプル（CFU/mL, Log10軸）

3群（A, B, C）× triplicate の生菌数データ（ワイド型）と、Rで増殖曲線を描画するスクリプトです。

1. データファイル

sample001.csv をダウンロード

  • 形式: ワイド型（列名 = 培養時間 0, 2, 4, 6, 8, 10, 24 h）
  • 群: A（典型的な増殖）、B（やや遅い増殖）、C（lag phase が長い増殖）
  • 値: 生菌数（CFU/mL）。0時間で約105、24時間で約109

2. Rスクリプト

sample001.csv と同じフォルダを作業ディレクトリにして実行してください（tidyverse が必要です）。

growth_curve.R
# ============================================
# 細菌増殖曲線（CFU/mL, Log10軸）
# ============================================
library(tidyverse)

# 1. 読み込み（ワイド型）
df_wide <- read_csv("sample001.csv")

# 2. ロング型へ変換 & 3. Hourを数値化
df_long <- df_wide %>%
  pivot_longer(
    cols      = -c(Group, Replicate),
    names_to  = "Hour",
    values_to = "CFU"
  ) %>%
  mutate(
    Hour  = as.numeric(Hour),
    Group = factor(Group, levels = c("A", "B", "C"))
  )

# 4. 群 × 時間ごとの平均値とSD
df_summary <- df_long %>%
  group_by(Group, Hour) %>%
  summarise(
    Mean = mean(CFU),
    SD   = sd(CFU),
    .groups = "drop"
  )

# 5. プロット
p <- ggplot(df_summary, aes(x = Hour, y = Mean, colour = Group, group = Group)) +
  geom_line(linewidth = 0.8) +
  geom_point(size = 3) +
  geom_errorbar(
    aes(ymin = Mean - SD, ymax = Mean + SD),
    width = 0.4, linewidth = 0.6
  ) +
  scale_y_log10(
    labels = scales::label_log(),
    breaks = scales::breaks_log(n = 6)
  ) +
  scale_x_continuous(breaks = c(0, 2, 4, 6, 8, 10, 24)) +
  scale_colour_brewer(palette = "Set1") +
  labs(
    x = "Time (Hours)",
    y = "CFU/mL",
    colour = "Group"
  ) +
  theme_classic(base_size = 14) +
  theme(
    panel.border    = element_rect(colour = "black", fill = NA, linewidth = 1),
    axis.line       = element_blank(),
    axis.text       = element_text(colour = "black"),
    legend.position = "right"
  )

print(p)

# 保存（論文用）
ggsave("growth_curve.png", p, width = 7, height = 5, dpi = 300)
ggsave("growth_curve.pdf", p, width = 7, height = 5)

3. グラフの作り変えヒント

以下は上のスクリプトの「# 5. プロット」部分を書き換えるためのヒントです。各コードの右上のボタンでコピーできます。

linewidth は ggplot2 3.4.0 以降の引数です。古い版では size を使ってください。凡例を図の内側に置く legend.position = "inside" は 3.5.0 以降です。

3-1. 線・点・エラーバーを太く／大きくする

geom_line の linewidth、geom_point の size、geom_errorbar の linewidth と width（キャップの横幅）を変更します。

線・点・エラーバーのサイズ
geom_line(linewidth = 1.5) +                       # 線の太さ（元: 0.8）
geom_point(size = 4) +                             # 点の大きさ（元: 3）
geom_errorbar(
  aes(ymin = Mean - SD, ymax = Mean + SD),
  width = 0.6, linewidth = 1.0                     # キャップの幅・線の太さ
) +

3-2. 色を変える

群ごとに色を直接指定するなら scale_colour_manual、既成パレットなら scale_colour_brewer(palette = ...) を使います。scale_colour_brewer(palette = "Set1") の行を差し替えてください。

色の指定（どれか1つを選ぶ）
# (a) 群ごとに手動指定（色名またはカラーコード）
scale_colour_manual(values = c(A = "#0072B2", B = "#D55E00", C = "#009E73")) +

# (b) 色覚多様性に配慮したパレット（"Dark2", "Paired", "Set2" なども可）
scale_colour_brewer(palette = "Dark2") +

# (c) 白黒印刷向けのグレースケール
scale_colour_grey(start = 0, end = 0.6) +

# (d) 全群を黒1色にしたい場合は、先頭の aes() から colour = Group を外し、
#     geom_line / geom_point / geom_errorbar に colour = "black" を指定する

3-3. 実線を点線にする

全部の線を変えるなら geom_line(linetype = ...)。群ごとに変えるなら aes(linetype = Group) を指定して scale_linetype_manual で割り当てます。線種は "solid"（実線）、"dashed"（破線）、"dotted"（点線）、"dotdash"、"longdash"、"twodash" が使えます。

線種の変更
# (a) 全部の線を点線にする
geom_line(linewidth = 0.8, linetype = "dotted") +

# (b) 群ごとに線種を変える（geom_line を次の2行に差し替える）
geom_line(aes(linetype = Group), linewidth = 0.8) +
scale_linetype_manual(values = c(A = "solid", B = "dashed", C = "dotted")) +

3-4. 点の形を群ごとに変える

shape に数値を指定します（16 = ●、17 = ▲、15 = ■、18 = ◆、1 = ○、2 = △、0 = □）。

点の形
geom_point(aes(shape = Group), size = 3) +
scale_shape_manual(values = c(A = 16, B = 17, C = 15)) +

3-5. 凡例の変更

位置・タイトル・ラベル（群名の表示）を変えられます。

凡例の位置・タイトル・ラベル
# --- 位置（theme() の中の legend.position を書き換える）---
legend.position = "bottom"      # "top", "left", "right", "bottom"
legend.position = "none"        # 凡例を消す
# 図の内側に置く（ggplot2 3.5.0 以降）。座標は 0〜1 の相対位置
legend.position = "inside",
legend.position.inside = c(0.15, 0.85)

# --- タイトル（labs() の colour を書き換える）---
labs(x = "Time (Hours)", y = "CFU/mL", colour = "Strain")
# タイトルを消す（theme() の中に追加）
legend.title = element_blank()

# --- ラベル（A, B, C の表示名を変える。scale_colour_*() の中に labels を追加）---
scale_colour_brewer(
  palette = "Set1",
  labels  = c(A = "Control", B = "Drug 1", C = "Drug 2")
) +

# --- 凡例に枠を付ける（theme() の中に追加）---
legend.background = element_rect(colour = "black", fill = "white")
色・線種・点の形を同時に群へ割り当てる場合は、凡例が分裂しないよう、labs() のタイトルと各 scale_*() の labels を揃えてください（例: labs(colour = "Strain", linetype = "Strain", shape = "Strain")）。

3-6. 色・線種・点の形をまとめて群ごとに変える（白黒印刷でも区別できる版）

「# 5. プロット」の p <- ggplot(...) から scale_colour_brewer(...) までを、次のように差し替えます。

colour + linetype + shape の併用
p <- ggplot(df_summary,
            aes(x = Hour, y = Mean, colour = Group,
                linetype = Group, shape = Group, group = Group)) +
  geom_line(linewidth = 1) +
  geom_point(size = 3.5) +
  geom_errorbar(
    aes(ymin = Mean - SD, ymax = Mean + SD),
    width = 0.5, linewidth = 0.6, linetype = "solid"
  ) +
  scale_y_log10(
    labels = scales::label_log(),
    breaks = scales::breaks_log(n = 6)
  ) +
  scale_x_continuous(breaks = c(0, 2, 4, 6, 8, 10, 24)) +
  scale_colour_manual(values   = c(A = "#0072B2", B = "#D55E00", C = "#009E73")) +
  scale_linetype_manual(values = c(A = "solid", B = "dashed", C = "dotted")) +
  scale_shape_manual(values    = c(A = 16, B = 17, C = 15)) +
  labs(x = "Time (Hours)", y = "CFU/mL",
       colour = "Group", linetype = "Group", shape = "Group") +
  theme_classic(base_size = 14) +
  theme(
    panel.border    = element_rect(colour = "black", fill = NA, linewidth = 1),
    axis.line       = element_blank(),
    axis.text       = element_text(colour = "black"),
    legend.position = "right"
  )

3-7. 軸・文字・保存サイズ

軸の範囲、全体の文字サイズ、外枠線の太さ、学名のイタリック表記、保存サイズの変更例です。

軸・文字・保存
# Y軸の表示範囲を固定する（+ の連結に追加）
coord_cartesian(ylim = c(1e4, 1e10)) +

# 全体の文字サイズ（theme_classic の base_size を変更）
theme_classic(base_size = 18) +

# 外枠線を太くする（theme() の panel.border の linewidth）
panel.border = element_rect(colour = "black", fill = NA, linewidth = 1.5)

# 学名をイタリックでタイトルに入れる（血清型などはイタリックにしない）
labs(title = expression(italic("Escherichia coli")),
     x = "Time (Hours)", y = "CFU/mL")
# 種名の後ろに血清型を付ける例: expression(italic("Salmonella") ~ "Typhi")

# 保存サイズ・解像度
ggsave("growth_curve.png", p, width = 8, height = 6, dpi = 600)

4. 注意点

  • 列名が数値のみ（0, 2, ...）でも read_csv は文字列の列名として読み込むため、pivot_longer 後に as.numeric() で数値化しています。
  • 対数軸では、エラーバーの下端（Mean − SD）が 0 以下になると描画できません。SDが大きい実測データでは、先に log10(CFU) へ変換してから平均・SDを計算する方法もあります。
