マウス治療実験の生存解析サンプル（Kaplan–Meier・log-rank・Cox）

対照群と用量の異なる治療群 2 群（各 n = 8）の生存データと、R での生存解析・作図コード、見た目を変えるためのヒントです。

データ Rコード 出力例と結果の読み方 見た目を変えるヒント 注意点

使い方

  1. sample003.csv を R の作業ディレクトリ（スクリプトと同じフォルダ）に保存します。
  2. コードは [1/5] → [5/5] の順に上から実行します（各ブロックのコピー、または 5 つまとめてコピー）。
  3. 必要なパッケージは tidyverse と survival（R に標準で付属）です。number at risk の表を付ける [4/5] の後半だけ patchwork が必要です（install.packages("patchwork")）。

1. データ：sample003.csv

sample003.csv をダウンロード

  • 実験デザイン: 3 群（Control、Low、High）× 各 n = 8 匹、観察期間 14 日。治療は Low 群が低用量、High 群が高用量。
  • 想定した結果: 対照群は 4〜7 日で全例死亡し、治療群は用量依存的に生存が改善します。
  • 実験を想定して作成した架空のサンプルデータです。

2. Rコード

  • [1/5] 読み込み、Kaplan–Meier 推定（中央生存期間、制限付き平均生存時間、指定日の生存率）
  • [2/5] ログランク検定（3 群全体、ペアワイズ + Holm 補正、用量依存性の trend 検定）
  • [3/5] Cox 比例ハザードモデル（ハザード比と 95% 信頼区間、比例ハザード性の確認）
  • [4/5] Kaplan–Meier 曲線（打ち切りマーク、log-rank の p 値、number at risk）
  • [5/5] ハザード比のフォレストプロット

（上から順に実行する一続きのスクリプトです）

[1/5] 読み込み・Kaplan–Meier 推定・要約
# ============================================================
# sample003 : マウス治療実験の生存解析（3群、各 n = 8）
# [1/5] 読み込み・Kaplan–Meier 推定・要約
# ============================================================
library(tidyverse)
library(survival)    # 生存解析（R に標準で付属）

# --- 1. 読み込み --------------------------------------------
#   Day   : 観察日数（死亡した日、または打ち切りの日）
#   Event : 1 = 死亡（イベント発生）、0 = 打ち切り（観察終了時に生存）
df <- read_csv("sample003.csv") %>%
  mutate(
    Group = factor(Group, levels = c("Control", "Low", "High")),   # 先頭 = 基準（対照群）
    Dose  = as.numeric(Group) - 1   # 用量レベル 0, 1, 2（用量依存性の検定用。実際の用量があれば置き換える）
  )

# 群ごとの例数・死亡数・打ち切り数
df %>%
  group_by(Group) %>%
  summarise(n = n(), deaths = sum(Event), censored = sum(Event == 0), .groups = "drop") %>%
  print()

# --- 2. Kaplan–Meier 推定 -----------------------------------
fit <- survfit(Surv(Day, Event) ~ Group, data = df)

# 中央生存期間（median）と 95% 信頼区間、14 日までの制限付き平均生存時間（*rmean）
print(fit, rmean = 14)
# median が NA の群は「生存率が 50% を下回らなかった」ことを意味する

# 指定した日の生存率（95% 信頼区間つき）。extend = TRUE で全員死亡後の日も表示する
summary(fit, times = c(5, 7, 10, 14), extend = TRUE)
[2/5] ログランク検定（全体・ペアワイズ・用量依存性）
# ============================================================
# [2/5] ログランク検定（全体・ペアワイズ・用量依存性）
# ============================================================
# --- 1. 3 群全体のログランク検定 ----------------------------
lr <- survdiff(Surv(Day, Event) ~ Group, data = df)
print(lr)
p_lr <- 1 - pchisq(lr$chisq, df = length(lr$n) - 1)
cat("Log-rank test: p =", signif(p_lr, 3), "\n")

# --- 2. ペアワイズのログランク検定（Holm 補正） --------------
pairs <- combn(levels(df$Group), 2, simplify = FALSE)   # 全ペアの組み合わせ

pw <- map_dfr(pairs, function(g) {
  d  <- df %>% filter(Group %in% g) %>% droplevels()
  sd <- survdiff(Surv(Day, Event) ~ Group, data = d)
  tibble(group1 = g[1], group2 = g[2],
         chisq = sd$chisq, p = 1 - pchisq(sd$chisq, df = 1))
}) %>%
  mutate(p_adj = p.adjust(p, method = "holm"))           # "bonferroni", "BH" なども可
print(pw)

# --- 3. 用量依存性の検定（trend） ---------------------------
# 用量レベル（0, 1, 2）を数値として入れた Cox モデルのスコア検定が、ログランクの trend 検定に相当する
cox_trend <- coxph(Surv(Day, Event) ~ Dose, data = df)
summary(cox_trend)
p_trend <- summary(cox_trend)$sctest[["pvalue"]]
cat("Trend test (score): p =", signif(p_trend, 3), "\n")
# 用量が 1 段階上がるごとのハザード比は exp(coef)。1 より小さければ用量依存的にリスクが下がる
[3/5] Cox 比例ハザードモデル（ハザード比）
# ============================================================
# [3/5] Cox 比例ハザードモデル（ハザード比）
# ============================================================
# --- 1. 3 群のモデル（対照群が基準） -------------------------
cox <- coxph(Surv(Day, Event) ~ Group, data = df)
summary(cox)
# exp(coef) がハザード比（HR）。HR < 1 は、基準の群より死亡のハザード（瞬間的な死亡リスク）が低いこと

# --- 2. すべてのペアのハザード比 ----------------------------
# 基準の群を変えて 3 群モデルを当てはめ、各比較の HR・95% 信頼区間・p 値を取り出す。
# ※ 2 群だけを抜き出して当てはめない。High vs Control のように、対照群の死亡がすべて
#    High 群の最初の死亡より前に起きていると（完全分離）、HR が推定できなくなる
hr_from <- function(ref) {
  d   <- df %>% mutate(Group = relevel(Group, ref = ref))
  fit <- coxph(Surv(Day, Event) ~ Group, data = d)
  broom::tidy(fit, exponentiate = TRUE, conf.int = TRUE) %>%
    transmute(
      comparison = paste(str_remove(term, "^Group"), "vs", ref),
      HR = estimate, conf.low, conf.high, p.value
    )
}

hr_pairs <- bind_rows(
  hr_from("Control"),                                           # Low vs Control, High vs Control
  hr_from("Low") %>% filter(!str_starts(comparison, "Control")) # High vs Low
) %>%
  mutate(p_adj = p.adjust(p.value, method = "holm"))            # Wald 検定の p 値を Holm 補正
print(hr_pairs)

# --- 3. 比例ハザード性の確認 --------------------------------
# p > 0.05 なら比例ハザード性を棄却できない（例数が少ないと検出力は低い）
cox.zph(cox)
[4/5] Kaplan–Meier 曲線（打ち切りマーク・p 値・number at risk）
# ============================================================
# [4/5] Kaplan–Meier 曲線（打ち切りマーク・log-rank の p 値付き）
# ============================================================
# --- 共通設定（色・テーマ） ---------------------------------
cols <- c(Control = "#555555", Low = "#E69F00", High = "#0072B2")

theme_paper <- theme_classic(base_size = 14) +   # base_size: 全体の文字サイズ
  theme(
    panel.border = element_rect(colour = "black", fill = NA, linewidth = 1),
    axis.line    = element_blank(),
    axis.text    = element_text(colour = "black")
  )

# --- 作図用データ（survfit の結果を表にする） ---------------
km <- broom::tidy(fit) %>%
  mutate(Group = factor(str_remove(strata, "^Group="), levels = levels(df$Group)))

# 0 日目（生存率 100%）の行を足して、曲線を 100% から始める
km0 <- tibble(Group = factor(levels(df$Group), levels = levels(df$Group)),
              time = 0, estimate = 1, conf.low = 1, conf.high = 1)
km_df <- bind_rows(km0, km) %>% arrange(Group, time)

p_lbl <- ifelse(p_lr < 0.001, "Log-rank p < 0.001", sprintf("Log-rank p = %.3f", p_lr))
x_max <- 14                                       # 観察期間（日）

# --- Kaplan–Meier 曲線 --------------------------------------
p_km <- ggplot(km_df, aes(x = time, y = estimate, colour = Group)) +
  geom_step(linewidth = 1) +                                   # 線の太さ
  geom_point(data = filter(km, n.censor > 0),                  # 打ち切りマーク（+）
             shape = 3, size = 3, stroke = 0.8, show.legend = FALSE) +
  annotate("text", x = 0.3, y = 0.05, hjust = 0,               # p 値の表示位置
           label = p_lbl, size = 4.5) +
  scale_colour_manual(values = cols) +
  scale_x_continuous(breaks = seq(0, x_max, by = 2), limits = c(0, x_max),
                     expand = expansion(mult = c(0.03, 0.03))) +
  scale_y_continuous(labels = scales::percent, limits = c(0, 1),
                     expand = expansion(mult = c(0.01, 0.02))) +
  labs(x = NULL, y = "Survival probability") +
  theme_paper +
  theme(legend.position = "top", legend.title = element_blank())

print(p_km)
ggsave("sample003_km.png", p_km, width = 6, height = 5, dpi = 300)

結果の読み方（このサンプルの場合）

  • 中央生存期間: Control 5.5 日、Low 9.5 日。High は生存率が 50% を下回らず、未到達（NA）です。
  • 14 日生存率: Control 0%（7 日までに全例死亡）、Low 25.0%（95% 信頼区間 7.5〜83.0%）、High 75.0%（50.3〜100%）。
  • 3 群全体のログランク検定: χ² = 26.7（自由度 2）、p = 1.6 × 10-6。
  • ペアワイズ（Holm 補正後）: Control vs Low p = 0.0011、Control vs High p = 0.00017、Low vs High p = 0.023。
  • 用量依存性（trend 検定）: p = 1.4 × 10-6。用量レベルが 1 段階上がるごとのハザード比は 0.108（95% 信頼区間 0.036〜0.323）です。
  • ハザード比（3 群モデル）: Low vs Control 0.068（0.013〜0.36）、High vs Control 0.012（0.0015〜0.105）、High vs Low 0.18（0.036〜0.93）。HR < 1 は、分母の群より死亡のハザードが低いことを表します。
  • 比例ハザード性: cox.zph の global p = 0.58 で、棄却されませんでした（n が小さいため検出力は低い点に注意）。
ハザード比の推定が不安定になる場合: 対照群の死亡がすべて治療群の最初の死亡より前に起きるデザイン（このサンプルの High vs Control）では、2 群だけを抜き出した Cox 回帰は完全分離になり、HR が推定できません（係数が無限大になり、coefficient may be infinite という警告が出ます）。このコードでは 3 群モデルから比較を取り出しているため推定できていますが、High vs Control の HR は点推定が極端に小さく、信頼区間も広いため、参考値として扱ってください。このような場合は、Firth 補正付き Cox 回帰（coxphf パッケージなど）や、log-rank 検定と生存率・中央生存期間による記述を中心にすることを検討します。

5. 注意点

  • Event の定め方: 死亡と、人道的エンドポイントによる安楽死を同じ「イベント」として扱うかは、実験の前に決めておきます。サンプリングのために予定どおり犠牲にした個体は、打ち切り（Event = 0）として扱います。
  • 打ち切りの扱い: 打ち切りの理由が生存・死亡と無関係であること（非情報的打ち切り）が前提です。
  • ログランク検定の前提: 群間のハザード比が時間によらずほぼ一定であることを想定します。曲線が交差する場合は適しません。初期の差を重視する Gehan-Breslow 検定は 4-5 を参照してください。
  • 小さい n: 各群 n = 8 では信頼区間が広くなります。Cox 回帰の Wald 検定の p 値は、イベント数が少ないと不安定なので、尤度比検定（4-5 の (d)）も併せて確認します。
  • 中央生存期間が NA: 生存率が 50% を下回らなかった群は中央生存期間が求まりません。その場合は 14 日生存率や制限付き平均生存時間（rmean）で比較します。
  • 多重比較: ペアワイズ log-rank と、HR の Wald 検定の p 値には、どちらも Holm 補正をかけています。
  • 用量依存性: trend 検定では用量レベルを 0、1、2 の等間隔として扱っています。実際の用量（mg/kg など）が分かる場合は、Dose 列をその数値（または対数用量）に置き換えてください。
  • 報告: 動物実験の論文では、例数、割り付け、盲検化、除外基準などを ARRIVE ガイドラインに沿って記載します。
  • 動作確認: R 4.3.3 / survival 3.5-8 / ggplot2 3.4.4 / tidyverse 2.0.0 / patchwork 1.2.0 / survminer 0.4.9 で動作確認しています。linewidth は ggplot2 3.4.0 以降の引数です。
