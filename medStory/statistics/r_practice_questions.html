Q25同じ患者10人の治療前後の収縮期血圧が次のとおりであった。治療前後で血圧に差があるかを検定しなさい。どのt検定を使いますか。★★

解答例を見る

Q34(1) サイコロを10回振る（同じ目が何度も出てよい）。(2) 1〜10の整数から、重複なく5個を選ぶ。それぞれを sample() で行いなさい。最後に、sample(1:5, size = 10) を実行するとどうなるか、理由とともに答えなさい。★★
解答例を見る 
set.seed(123)

sample(1:6, size = 10, replace = TRUE)   # (1) 復元抽出

Q35赤玉3個、白玉2個が入った袋から、玉を2回引く。「2回とも赤」になる確率を、(1) 引いた玉を戻す場合、(2) 戻さない場合の両方で、手計算で求め、さらにシミュレーション（10000回）でも確かめなさい。★★★
解答例を見る

手計算：(1) 3/5 × 3/5 = 0.36　(2) 3/5 × 2/4 = 0.30

set.seed(1)
bag <- c("赤", "赤", "赤", "白", "白")

# (1) 戻す（復元抽出）
mean(replicate(10000, all(sample(bag, 2, replace = TRUE) == "赤")))

# (2) 戻さない（非復元抽出）
mean(replicate(10000, all(sample(bag, 2, replace = FALSE) == "赤")))

(1) は0.36前後、(2) は0.30前後になります（乱数なので、ぴったりにはなりません）。replicate() が10000回の繰り返しを行い、all() が「2回とも赤か」を判定し、mean() が、TRUE の割合（確率）を求めます。

Q37a <- c(1,2,3,4)、b <- c(3,4,5,6) について、「a + b を計算 → 小さい順に並べ替え → 5より大きいものを取り出す」処理を、(1) 入れ子（マトリョーシカ）、(2) パイプ |>、(3) tidyverseの %>% の3通りで書きなさい。★★★
解答例を見る 
a <- c(1, 2, 3, 4)
b <- c(3, 4, 5, 6)

# (1) 入れ子
subset(sort(a + b), sort(a + b) > 5)

# (2) Base Rのパイプ（無名関数を使う）
(a + b) |> sort() |> (\(x) x[x > 5])()

# (3) tidyverse：表（データフレーム）にして、列名で指定
data.frame(value = a + b) %>%
  arrange(value) %>%
  filter(value > 5)

どれも、結果は 6、8、10です。

Q46有意水準5%のt検定を、(1) 3回、(2) 10回繰り返したとき、少なくとも1回は誤って有意になる確率の目安（検定が独立と仮定）を計算しなさい。これは何の問題を表していますか。★★
解答例を見る 
1 - 0.95^3      # 約 0.143（14%）
1 - 0.95^10     # 約 0.401（40%）

検定を繰り返すほど、偶然の差を有意と誤判定する確率が上がります。これが多重性の問題です。3群以上の比較では、ANOVAでまず全体を1回で検定し、その後の多重比較で補正します。

F ≈ 1180（自由度 2 と 147）で、p値は極めて小さく（< 2e-16 と表示）、種によって平均値が異なります。Tukey法の多重比較では、3つの組み合わせ（versicolor-setosa、virginica-setosa、virginica-versicolor）のすべてで、有意な差があります。

ANOVAは「どこかに差がある」ことしかわからないので、どの間に差があるかは、多重比較で調べます。

Q50Q49のデータで、コックス比例ハザードモデルを当てはめなさい。ハザード比が「0.6」と出た場合、どう解釈しますか。★★★

ヒント：基準にする群を先頭にするために、factor() の levels を指定します。

解答例を見る 
surv_data$group <- factor(surv_data$group, levels = c("Standard", "New"))

fit_cox <- coxph(Surv(time, status) ~ group, data = surv_data)
summary(fit_cox)       # exp(coef) がハザード比（New群 / Standard群）
cox.zph(fit_cox)       # 比例ハザード性の確認

この例では、New群のほうがイベントが少ないので、ハザード比は1より小さくなります。

ハザード比「0.6」は、「基準の群に比べて、どの時点でも、イベントの起きる勢い（ハザード）が0.6倍、つまり40%低い」という意味です。「40%の人が助かる」「累積のリスクが40%減る」という意味ではありません。比例ハザード性（ハザード比が時間によらず一定）が、前提です。

コホート研究症例対照研究

Q58コホート研究で、喫煙者200人のうち40人、非喫煙者300人のうち30人が、10年間に病気を発症した。リスク（発症割合）、リスク比、リスク差、オッズ比を求めなさい。★★
解答例を見る 
a <- 40; b <- 160     # 喫煙者：発症あり、なし
c <- 30; d <- 270     # 非喫煙者：発症あり、なし

a / (a + b)                          # 喫煙者のリスク 0.20
c / (c + d)                          # 非喫煙者のリスク 0.10
(a / (a + b)) / (c / (c + d))        # リスク比 2.0
(a / (a + b)) - (c / (c + d))        # リスク差 0.10
(a * d) / (b * c)                    # オッズ比 2.25

喫煙者の発症リスクは、非喫煙者の2倍（リスク比2.0）で、リスク差は10ポイントです。オッズ比（2.25）は、リスク比（2.0）より大きく、発症が、まれではないために、差が出ています。

Q59症例対照研究で、症例50人のうち35人が曝露あり、対照100人のうち30人が曝露ありであった。オッズ比を求めなさい。また、この研究でリスク比を求められないのは、なぜですか。★★★
解答例を見る 
# 症例：曝露あり35、なし15　対照：曝露あり30、なし70
(35 * 70) / (15 * 30)      # オッズ比 約5.44

オッズ比は約5.44です。

症例対照研究では、症例と対照の人数（ここでは50人と100人）を、研究者が決めて集めています。そのため、「曝露ありの人のうち、発症した割合」（35/65）は、対照を何人集めるかで変わってしまい、本当のリスクを表しません。リスク比は求められません。一方、オッズ比は、「曝露のオッズの比」と「病気のオッズの比」が等しい性質があるため、結果から出発する研究でも、正しく推定できます。

Q62「カルバペネム系抗菌薬の使用歴と、カルバペネム耐性菌の検出との関連」を、症例対照研究で調べる。PECO（対象、曝露、比較、結果）を書き、症例と対照を、どう選ぶか答えなさい。★★★
解答例を見る
  • P（対象）：入院患者
  • E（曝露）：カルバペネム系抗菌薬の使用歴
  • C（比較）：使用歴がない
  • O（結果）：カルバペネム耐性菌の検出

症例は、耐性菌が検出された患者です。対照は、同じ施設・同じ期間に入院した、耐性菌が検出されていない患者から選びます。対照の選び方に偏りがあると、選択バイアスが生じるため、年齢や入院期間などが、症例と似るように選ぶ（マッチングする）ことがあります。説明変数は抗菌薬の使用歴、目的変数は耐性菌の検出の有無です。

Q6320人の患者を、ランダムに、介入群10人と対照群10人に割り付けるコードを書きなさい。なぜ、ランダム化が重要ですか。★★

ヒント：rep() で群のラベルを作り、sample() で並べ替えます（非復元抽出）。

解答例を見る 
set.seed(2026)
patients <- data.frame(id = 1:20)
patients$group <- sample(rep(c("介入", "対照"), each = 10))   # 10人ずつを並べ替え
table(patients$group)      # 介入10、対照10

ランダム化によって、年齢や重症度などの背景（測定していないものも含む）が、偶然を除いて、2群で同程度になります。そのため、2群の差を、介入の効果と考えやすくなります。
