① 背景（導入）約3分

  • 「酵母などでも知られている」の話は、時間が厳しければ口頭で一言か削除でよい。
  • QS のヒエラルキー図：Las → Rhl / PQS → 病原因子。今回の対象 RhlR を色や枠で強調する。
  • 「なぜ RhlR か」を1文で。「未解明だから」に加えて、「未解明の理由＝リガンド（AHL）が無いアポ体で不溶性・不安定だから」までをセットで言うと、目的（可溶化）に自然につながる。さらに、lasR 変異株の臨床分離株でも Rhl 系が機能し得る、などのRhlR をねらう意義が言えれば強い（根拠となる文献を確認のうえ記載）。

概念一言での説明この研究との関係・聞かれそうな点
プロモーターとコンセンサス配列 RNAポリメラーゼが結合して転写を始める領域。大腸菌の主要シグマ因子（σ70）が認識する典型配列は −35 領域（TTGACA 型）と −10 領域（TATAAT 型）。「コンセンサス配列」とは、多数の配列を比べて最も多く現れる共通配列のこと。 PrhlA・PphzA にも −35／−10 に相当する領域があり、その近くに RhlR（LuxR型）の結合配列がある。「コンセンサスからどれだけ外れているか」が、プロモーターの強さ・活性化への依存度の差につながるという説明が、考察の PrhlA と PphzA の相違に使える。
転写因子の結合配列（lux box 型） LuxR型の受容体が結合する約20 bp の、回文構造（パリンドローム）に似た配列。複数のプロモーターで一部の塩基が保存されている（資料では「CT … 12 bp … AG」）。 配列の一部が違うと、RhlR との結合の強さや、PqsE への依存度が変わり得る。2つのプロモーターの結合配列を並べて、一致する塩基・異なる塩基を色分けした図を予備スライドに。「その違いがデータの差を説明できるか」を聞かれたら、仮説として答える（本研究のデータでは検証していないため）。
転写開始点（TSS, +1） mRNA の最初の塩基に対応するDNA上の位置。塩基番号の基準で、上流は −1, −2…（0 は使わない）、下流は +2, +3… と数える。 レポーター構築で、プロモーター断片に TSS が含まれているか（どこから lacZ までをつないだか）を説明できること。結合配列の位置を「TSS から約 −◯ 塩基」と言える数値は、必ず原著論文で確認して入れる（資料中の「約(-)」は空欄のまま）。
翻訳開始点（開始コドン）と 5′UTR 翻訳が始まる ATG（まれに GTG、TTG）。TSS と ATG の間が 5′非翻訳領域（5′UTR）で、細菌ではリボソーム結合部位（SD配列）がここにある。 「P–lacZ では、天然の rhlA の ATG の代わりに lacZ の ATG を使うのか、rhlA の5′UTR を含むのか」を聞かれやすい。つなぎ目の設計を自分で説明できるようにする。コード領域の番号付けでは ATG の A を +1 とする別の流儀があるため、「TSS 基準」か「ATG 基準」かを区別して話す。
オペロンとポリシストロニック オペロン＝同じプロモーターで一緒に転写される遺伝子の集まり。1本の mRNA に複数の遺伝子が載るのがポリシストロニック（例：rhlAB、phzA–G）。 PrhlA–lacZ では rhlB も rhlA も含まれず、lacZ が代わりに入る。「lacZ の活性は、オペロン全体の発現を代表する指標」と言えるのは、プロモーターが共通だから。天然では rhlC は別の転写単位であることにも注意。
モノシストロニック 1本の mRNA に1つの遺伝子だけが載る形。 レポーター構築（P–lacZ）は1遺伝子の単純な転写単位なので、発現量＝プロモーター活性として解釈しやすい、と説明できる。
シャペロン（PqsE の moonlighting chaperone） 他のタンパク質の折りたたみや安定化を助けるタンパク質。PqsE は本来、PQS 合成に関わる酵素だが、RhlR と複合体を作って RhlR を可溶化・安定化させる、シャペロン様の働きがあると報告されている（Borgert ら, 2022）。 本研究の最重要の背景。アポ体の RhlR が不溶性・不安定であるのは、PqsE や C4-HSL のような安定化因子がないとき。大腸菌のレポーター系には pqsE がない。「PqsE なしで RhlR を可溶化・安定化させる」のが、変異体作製の狙い、と位置づけられる。PrhlA は PqsE 非依存的、PphzA は PqsE 依存性が強いと報告されており、「なぜ PphzA を使ったか」の考察に直結する（※要確認の仮説の項を参照）。

考察に使える視点（データで支持される範囲だけ使うこと）

  • 大腸菌には pqsE がないので、PphzA（PqsE 依存性が強い）で活性が測れたとすれば、「変異で可溶化・安定化した RhlR が、PqsE の助けなしでも活性を示した」という解釈が一つの仮説になる。逆に PrhlA（PqsE 非依存）での差が小さければ、そのこととも整合するか確認する。
  • ただし、PqsE の効果は「溶解度」だけでなく、RhlR の DNA 結合やプロモーター選択性への影響も報告されている。「PqsE＝単なるシャペロン」と単純化せず、PqsE の機能は議論が続いていると一言添える。
  • N末5〜8番目の位置が、PqsE との結合面と重なるかどうかは、構造論文で確認しておく（重なるなら、変異の効果を解釈する鍵になる）。
