TAXONOMY

タキソノミー（分類学）とは

生物を整理し、名前をつけ、見分けるためのルールや学問そのものです。細菌学のタキソノミーは、3つの作業からなります。

1

分類 Classification

似た性質や遺伝子をもつ細菌をグループ分けし、階層に当てはめる。

2

命名 Nomenclature

国際的なルール（国際原核生物命名規約）に従って、世界共通の学名（ラテン語）をつける。

3

同定 Identification

目の前の未知の細菌が、すでに登録されているどの菌と同じかを、グラム染色や遺伝子検査などで突き止める。

分類の階層

※大腸菌を例にした図です。ドメイン〜科の名前は、私が補った一般的な分類です（補足）。界（Kingdom）はPseudomonadatiです。ただし、教科書では界を省いてドメインから門へ進む説明も多いので、使う資料に合わせてください。

CHECK 1タキソノミー（分類学）の3つの作業の組み合わせは？

正解：分類・命名・同定。グループ分けし、世界共通の名前をつけ、未知の菌がどれにあたるかを突き止める、という流れです。

CHECK 2分類の階層を、大きなくくりから順に並べると？

正解：1番目。英語では Domain → Kingdom → Phylum → Class → Order → Family → Genus → Species。目・科まででよい菌もあれば、種まで知っておくべき菌もあります。
NAME CHANGES

なぜ名前が変わるのか

技術が進むにつれて、「実は別の菌だった」「近縁の別の属に入れるべきだった」と判明し、菌の名前や分類が途中で変わることがよくあります。これらを正しく管理するために、タキソノミーが必要です。

CHECK 3菌の学名が途中で変わる主な理由は？

正解：3番目。タキソノミーという学問が進み、その最新結果が名前に反映されます。
BINOMIAL NOMENCLATURE

リンネの二名法：属名＋種小名

18世紀の博物学者 Carl von Linné（リンネ）が体系化した、学名を属名と種小名の2語（ラテン語）で表す世界共通のルールです。

人間にたとえると、「苗字（属名）」＋「名前（種小名）」のセットです（日本語の姓名と同じ順）。

和名属名（大文字で開始）種小名（小文字で開始）学名（略記）
大腸菌Escherichia（エシェリヒア属）coli（大腸の）Escherichia coli（E. coli）
黄色ブドウ球菌Staphylococcus（ブドウ球菌属）aureus（黄金色の）Staphylococcus aureus（S. aureus）

書き方の鉄則

  • 必ずイタリック体（斜体）で書く。
  • 1語目の属名の頭文字だけを大文字にし、2語目の種小名は小文字で始める。
  • 2回目以降は、属名を略して E. coli のように、頭文字だけで書いてよい。
  • 血清型（serovar）はイタリックにしない（Salmonella Typhi）。詳しくは前の章を参照。
補足：Escherichia は人名（Theodor Escherich）に由来します。Staphylococcus は、ギリシャ語の「ブドウの房」＋「粒」からできた名前です。

CHECK 4学名の正しい書き方は？

正解：2番目。属名は大文字で始め、種小名は小文字で始め、全体をイタリックで書きます。

CHECK 5二名法で、「苗字」にたとえられるのは？

正解：属名。苗字（属名）＋名前（種小名）のセットです。

CHECK 6Staphylococcus aureus を2回目以降に略記すると？

正解：S. aureus。属名の頭文字＋ピリオド＋種小名、です。
LPSN

LPSN：細菌の「公式な名簿」

LPSN（List of Prokaryotic names with Standing in Nomenclature）は、命名法上、正式と認められた原核生物（細菌・古細菌）の公式名簿のウェブデータベースです。

  • 正式な名前になる条件：新種を発見して名前をつけても、勝手に名乗るだけでは、正式な学名として認められません。国際的な専門誌（IJSEM など）に論文が掲載され、所定の手続きを経て、はじめてLPSNに登録されます。
  • 運営：1997年にフランスの Jean P. Euzéby 教授らが創始し、現在はドイツの Leibniz Institute DSMZ が維持・運営しています。
  • 調べられること：現在の正しい学名、過去の古い名前（シノニム／同義語）、名前の由来（語源）、分類上の位置づけ（どの科・どの属か）。
タキソノミーLPSN
たとえると法律・ルール・学問公式な戸籍台帳（データベース）
役割どう分類し、どう名前をつけるかを決めるルールに基づいて承認された名前を載せる
使いどころ：「この菌の名前、今はどう書くのが正しいのか」「昔の名前は何だったのか」を確かめるときは、LPSNで調べましょう。

CHECK 7LPSNとは？

正解：2番目。現在の正しい学名や、過去の名前（シノニム）、語源、分類上の位置づけを調べられます。

CHECK 8タキソノミーとLPSNの関係を、たとえで言うと？

正解：1番目。タキソノミーが決め、LPSNがその結果を載せています。
SPECIES BOUNDARY

「同じ種」と「別の種」の境界線：DDHとANI

新しい名前（種小名）をつけるには、その菌が本当に新種かどうかを、科学的に示す必要があります。人間や動物は、見た目や、交配して子ができるかで種を分けますが、細菌は分裂して増える単細胞生物なので、その方法が使えません。

DDH：DNAの「くっつき度」を測る

2つの菌からDNAを取り出す→一本鎖にほどく→混ぜて、結合（ハイブリダイズ）の程度を測る

DDH（DNA-DNAハイブリダイゼーション）は、2つの異なるDNAが、どれくらい結合するかを調べる実験です。塩基配列が似ているほど、よく結合します。

国際的な細菌分類のルールでは、DDHの結合値が70%以上なら同じ種、70%未満なら別の種（新種候補）とされてきました。

現在の主流：ANI

現在は、次世代シークエンサーで全ゲノムを解読できるため、DDH自体はほとんど行われなくなりました。かわりに、パソコン上でゲノムの一致度を計算する ANI（Average Nucleotide Identity：平均塩基同一性）が主流です。

※模式図です。ANIの数直線は、見やすさのために0〜100%で描いています。

DDHANI
方法DNAを取り出して結合の程度を測る、実験（ウェット）全ゲノムの配列を、コンピュータ上で比べる
境界線70%約95〜96%
現在ほとんど行われない主流
受け継がれた考え方：デジタルにゲノムを比較できるようになっても、「％の境界線で、種をバシッと分ける」という、DDHがつくった考え方は、形を変えて生き続けています。

CHECK 9従来、DDHで「同じ種」とされた結合値は？

正解：70%以上。70%未満は別の種（新種候補）です。95〜96%は、現在のANIの境界線です。

CHECK 10DDHにかわって現在主流になった、ゲノムの一致度を計算する指標は？

正解：ANI。平均塩基同一性（Average Nucleotide Identity）です。境界線は約95〜96%です。

CHECK 11細菌で、動物のように「交配して子ができるか」で種を分けられない理由は？

正解：分裂して増える単細胞生物だから。そこで、DNAの類似度という「科学的な物差し」が必要になりました。
CLINICAL CONNECTIONS

臨床とのつながり：分類学と臨床のずれ

この節は、元の資料にない補足です。遺伝子による「種」と、臨床での「名前」は、必ずしも一致しません。

🧬 Salmonella Typhi は「種」ではない

チフス菌は、独立した種ではなく、Salmonella enterica の血清型（serovar）の一つです。種より下の区分なので、Typhi はイタリックにしません。

⚖️ 赤痢菌と大腸菌

遺伝的には、Shigella 属の菌は E. coli と同じ種の範囲に入ることが知られています。しかし、臨床的には病気の性質が大きく異なるため、歴史的な名前が使い続けられています（補足）。

つなげて考える：タキソノミーは、遺伝子を軸にして更新されますが、臨床では、病気の起こし方・治療・感染対策の違いが大切です。両方の見方を知っていると、検査報告の菌名の意味が、立体的に見えてきます。

CHECK 12Salmonella Typhi の「Typhi」が表すものは？

正解：血清型。チフス菌は Salmonella enterica の血清型の一つで、Typhi はイタリックにしません。
BELOW SPECIES

「種」より下：亜種・型・株と、sp. / spp.

同じ「種」でも、性質や遺伝子、毒性が少しずつ違うことがあります。そのとき、学名の後ろにつけて区別する記号や用語を整理します。

① 正式な分類単位：亜種（subsp.）

subsp.（subspecies の略）は、同じ種の中で、遺伝的・性質的に明確な違いがあるグループを公的に分けるときに使います。現在の細菌学で、種の下の分類単位として正式に認められているのは、基本的にこれです。

  • subsp. はイタリックにせず、ピリオドをつける（亜種名の部分はイタリック）。
  • 例：Lactobacillus delbrueckii subsp. bulgaricus（ヨーグルトで有名な「ブルガリア菌」。L. delbrueckii という種の中の、ブルガリア亜種）
var.（変種：variety）は、かつて subsp. と同じような意味で広く使われていました。現在の細菌学（LPSNなど）では、原則として使われなくなり、subsp. に統一される傾向があります。植物学や、古い菌名には、今も残っています。

② 分類階層ではない「型」と「株」

次のものは、門・綱・目…のような正式な階層ではありません。しかし、医療や研究では必須の知識です。

用語何で分けるか例
serovar / serotype

イタリックの規則：血清型（serovar）の名前（Typhimurium など）や、株の名前（K-12 など）はイタリックにしません。イタリックになるのは、属名・種小名（と亜種名）です。

③ 論文でよく見る sp. と spp.

これはバリエーションの単位ではなく、名前を省略・特定しないときの便利な記号です。

記号意味例
sp.species の単数形。属名は分かっているが、具体的な種までは特定できない（しない）1種の菌Staphylococcus sp.（ブドウ球菌属のなにか1種）
spp.species の複数形。その属に含まれる複数の種をまとめて指すLactobacillus spp.（ラクトバチルス属の菌たち）
補足：sp. と spp. は、ふつうイタリックにしません（属名の部分だけがイタリック）。
まとめ：正式な分類としては、「種」の下は亜種（subspecies）が基本です。しかし、実際の医療や食品の世界では、毒性や役割が大きく異なるため、血清型や株という、さらに細かいラベルで菌をピンポイントに特定します。

CHECK 13現在の細菌学で、「種」の下の正式な分類単位として基本になるのは？

正解：1番目。血清型や株は、医療や研究では必須ですが、正式な分類階層ではありません。

CHECK 14Lactobacillus spp. が指すのは？

正解：3番目。spp. は複数形で、その属の複数の種をまとめて指します。1種で種名が不明なときは sp. です。
