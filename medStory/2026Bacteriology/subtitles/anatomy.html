ANATOMY × INFECTION

肺炎を理解するには、
まず肺を知る。

感染症の病態は、感染巣となる臓器の「解剖学的区画」で決まります。どこまで細菌が達しているのか、そこからどこへ広がるのか。解剖を感染症の言葉で読み直すサブテキストです。

POINT

この章の考え方

感染症の病態は、臓器の解剖学的区画（どこまで病原体が達しているか）と、その臓器の生理学的指標（検査値）をセットで押さえると理解しやすくなります。区画は、重症度の判定、画像診断、抗菌薬の選択に直結します。

  • 肺炎：気道の分岐、肺葉・肺区域
  • 髄膜炎：髄膜の層構造
  • 尿路感染症：上部尿路と下部尿路
  • 骨髄炎：骨の血流分布（年齢で変わる）
  • 肝・胆・脾：区域、類洞、脾臓の血液ろ過機能

検査値の読み方は生理学・生化学のサブテキストで扱います。ここでは「構造」に集中しましょう。

BASIC

上皮と内皮は、発生から違う

上皮epithelium

体表・管腔の表面を覆う細胞。外胚葉または内胚葉由来。気道上皮、腸管上皮、尿路上皮、肺胞上皮など。

感染症では、病原体が最初に出会う「入口」です。

内皮endothelium

血管・リンパ管・心臓の内面を覆う細胞。中胚葉由来。血管内皮、心内膜など。

血行性感染や、血液脳関門の通過を考えるときの主役です。

CHECK 1心内膜を構成する内皮細胞は、どの胚葉に由来する？

正解：中胚葉。内皮は中胚葉由来です。上皮は外胚葉または内胚葉由来、と対にして覚えましょう。
RESPIRATORY

肺：肺炎を理解するための解剖

気道の分岐

気管から肺胞まで、気道は約23回分岐します。前半が空気の通り道（導管部）、後半がガス交換の場（呼吸部）です。

気管 → 気管支 → 肺葉気管支 → 区域気管支 → 細気管支 → 終末細気管支（ここまで導管部）
→ 呼吸細気管支 → 肺胞管 → 肺胞（呼吸部）

肺葉と肺区域

肺葉

  • 右肺：上葉・中葉・下葉の3葉
  • 左肺：上葉・下葉の2葉

肺区域（Boyden分類）

  • 右：10区域
  • 左：8〜10区域（資料により表記が異なる）
胸部X線・CTでの使い方：浸潤影がどの葉・区域にあるかを、解剖に当てはめて評価します。陰影の分布が、肺炎の型の鑑別に役立ちます。
型画像の特徴
大葉性肺炎一つの肺葉・区域に限局する均一なconsolidation
気管支肺炎両側びまん性、肺底部優位の斑状陰影
非定型肺炎間質性陰影

肺胞とKohn孔

肺胞の壁は非常に薄く、I型肺胞上皮細胞（ガス交換）とII型肺胞上皮細胞（サーファクタント産生）からなります。隣り合う肺胞同士はKohn孔という小さな孔でつながっています。

Kohn孔はマクロファージなど免疫細胞の通り道です。一方で、肺炎球菌（Streptococcus pneumoniae）が肺胞から肺胞へ次々と広がり、一つの肺葉を埋めていく大葉性肺炎の進展様式にも関与すると考えられています。

CHECK 2隣り合う肺胞をつなぎ、免疫細胞の通り道になる一方、肺炎の波及にも関わる構造は？

正解：Kohn孔。Disse腔は肝臓の類洞周囲腔、Oddi括約筋は胆管・膵管の出口にある構造です。後で出てきます。

CHECK 3一つの肺葉・区域に限局する均一な浸潤影が典型的な肺炎は？

正解：大葉性肺炎。気管支肺炎は斑状、非定型肺炎は間質性陰影が特徴です。
CENTRAL NERVOUS SYSTEM

髄膜：3層構造と、くも膜下腔

髄膜は外側から硬膜 → くも膜 → 軟膜の3層です。くも膜と軟膜の間のくも膜下腔を髄液が満たしています。

細菌は、血液脳関門（脳の血管内皮）または血液髄液関門（脈絡叢）を越えてくも膜下腔に達します。炎症はくも膜下腔から脳実質へ波及しうるため、細菌性髄膜炎は緊急の疾患です。

つなげて考える：髄膜炎の原因菌には、肺炎球菌（Streptococcus pneumoniae）、髄膜炎菌（Neisseria meningitidis）、Haemophilus influenzae type b などがあります。いずれも莢膜をもつ菌です。莢膜は、診断と予防（ワクチン）にも関係します。

髄液の正常値と、細菌性・ウイルス性・結核性の違いは、生理学・生化学のサブテキストで扱います。

CHECK 4髄膜を外側から並べた順序として正しいものは？

正解：硬膜 → くも膜 → 軟膜。髄液が入るくも膜下腔は、くも膜と軟膜の間にあります。
URINARY TRACT

尿路：上部と下部で、病態が変わる

範囲疾患症状
下部尿路膀胱・尿道膀胱炎・尿道炎頻尿、尿意切迫、排尿時痛、恥骨上痛
上部尿路尿管・腎腎盂腎炎上記に加えて、発熱、側腹部・背部痛などの全身症状

女性は尿道が短く、尿道口が腟・肛門に近いため、男性よりも尿路感染症にかかりやすくなります。原因菌の約50〜80%は大腸菌（Escherichia coli）で、下部の感染が上行して腎盂腎炎に至る経路が典型的です。

CHECK 5発熱と側腹部痛を伴う尿路感染症で、主に感染が及んでいる部位は？

正解：腎（上部尿路）。発熱や側腹部・背部痛は腎盂腎炎を示唆します。
BONE & SPINE

骨と脊椎：血流の違いが、感染の場所を決める

長管骨の区分

外側は緻密な皮質骨、内部は骨髄腔、皮質骨の表面は骨膜が覆います。成長期には骨幹端と骨端の間に骨端線（成長板）があります。骨髄は、血行性の感染が定着しやすい場でもあります。

小児と成人で、好発部位が違う

年齢血管・骨の特徴感染の広がり
乳児（〜1歳）骨端軟骨を貫く血管（transphyseal vessels）がある骨幹端から骨端・関節腔へ波及しやすく、化膿性関節炎を合併しやすい
幼児〜小児骨端線が相対的に無血管。骨膜が厚く、疎に付着骨幹端に好発。骨膜下に広がり、骨膜下膿瘍をつくりやすい
青年後期〜成人骨端線が閉鎖。骨膜が肥厚し強固に付着感染は骨内に限局しやすい。長管骨の血行性骨髄炎はまれ
なぜ骨幹端？小児の骨幹端では毛細血管が屈曲して血流が緩やかで、毛細血管の端が開放構造をとるため、細菌が定着しやすいと考えられています。

CHECK 6小児の血行性骨髄炎が長管骨で最も好発する部位は？

正解：骨幹端。血流が緩徐で、毛細血管端が開放構造のため細菌が定着しやすい部位です。

脊椎：成人の血行性骨髄炎は椎体に多い

成人の血行性骨髄炎は、長管骨よりも椎体に好発します。椎体は血流の豊富な海綿骨で、椎体終板付近に動脈の終末枝が多く分布します。感染はまず椎体終板の下に生じ、続いて血流に乏しい椎間板へ進みます。

  • 脊椎炎（spondylitis）：椎体・終板の感染
  • 椎間板炎（discitis）：椎間板の感染
  • 脊椎椎間板炎（spondylodiscitis）：両者の合併

最多の原因菌は黄色ブドウ球菌（Staphylococcus aureus）。経路は、血行性（心内膜炎などからの播種）、直接接種（穿刺・手術）、隣接組織からの波及の3つです。好発部位は腰椎（約45%）、胸椎（約35%）、頸椎（約20%）の順です。

骨髄炎のその後と、関節との関係

骨髄内で炎症と膿瘍が生じると髄内圧が上がり、滲出液が皮質骨を貫いて骨膜下膿瘍になります。壊死した骨が腐骨（sequestrum）、骨膜の反応でできる新生骨がinvolucrumです。

股関節や肩関節のように、関節包が骨幹端に付着する部位では、骨幹端の感染が関節腔へ直接波及し、化膿性関節炎を合併しやすくなります。人工関節では、黄色ブドウ球菌のほか、コアグラーゼ陰性ブドウ球菌のような低病原性菌も原因になります。

CHECK 7骨髄炎で、壊死した骨を何と呼ぶ？

正解：腐骨。Involucrumは、腐骨を取り囲む新生骨のことです。
LIVER · BILIARY · PANCREAS

肝臓・胆道・膵臓

肝臓：8区域と類洞

肝臓は右葉・左葉に分かれ、さらにCouinaud分類の8区域（I〜VIII）に区分されます。各区域が独立した門脈枝・肝静脈枝・胆管枝をもつため、膿瘍や腫瘍は区域単位で局在しやすく、区域切除も可能になります。化膿性肝膿瘍もアメーバ性肝膿瘍（Entamoeba histolytica）も、右葉に多く見られます。

類洞（sinusoid）

門脈血（腸管由来）と肝動脈血が合流して流れる特殊な毛細血管網。内皮に小孔があり、血流が緩やかです。門脈血には腸内細菌由来の成分（リポ多糖など）が多く含まれます。

クッパー細胞

類洞内にいる肝の常在マクロファージ。血中の細菌を強力に捕捉します。肝硬変では防御が弱まり、細菌感染症のリスクが上がります。

Disse腔と伊藤細胞

類洞と肝細胞の間のすき間がDisse腔。そこにいる伊藤細胞（肝星細胞）は普段ビタミンAを貯蔵し、慢性の傷害で活性化すると線維化を進めます。

肝臓の免疫寛容

腸管由来の抗原が常に流入するため、クッパー細胞や類洞内皮などが免疫抑制性の因子を出し、過剰な反応を抑えています。

胆嚢・胆管

胆嚢は胆汁を濃縮・貯留する臓器です。胆嚢管が胆石などで閉塞すると、内圧が上がって二次的に細菌感染を起こし、急性胆嚢炎になります。原因菌は大腸菌（Escherichia coli）、Klebsiella属、Enterococcus属などです。

正常な胆管は、胆汁の流れ、Oddi括約筋、胆汁酸、IgAなどにより無菌に保たれています。胆管が結石などで閉塞すると、十二指腸からの逆行性感染が成立し、急性胆管炎（発熱・黄疸・右上腹部痛）に至ります。

ポイント：胆管の「通り道」が塞がること（閉塞）が、感染の引き金です。胆管炎は敗血症や肝膿瘍に進むことがあります。

膵臓

膵臓は、消化酵素を出す外分泌部（膵管から十二指腸へ）と、内分泌部（ランゲルハンス島）からなります。島は膵臓全体の約1〜2%で、α細胞（グルカゴン）、β細胞（インスリン、島の約60〜80%）、δ細胞（ソマトスタチン）が含まれます。

急性膵炎は外分泌組織の自己消化性の炎症です。重症例では壊死部に細菌が感染する感染性膵壊死を合併することがあります。

CHECK 8肝臓で、門脈血に由来する腸管由来の細菌や内毒素を、類洞内で捕捉する細胞は？

正解：クッパー細胞。肝の常在マクロファージです。伊藤細胞は線維化に関わる細胞で、II型肺胞上皮細胞はサーファクタントを産生します。
SPLEEN

脾臓：血液のフィルター

脾臓は赤脾髄と白脾髄からなる二次リンパ器官です。古くなった赤血球や、細胞内の粒子の除去、抗体（オプソニン）で標識された血中微生物の貪食、メモリーB細胞によるIgM産生を担います。

特に、莢膜をもつ細菌の血中からの除去に欠かせません。

肺炎球菌 Streptococcus pneumoniae 髄膜炎菌 Neisseria meningitidis Haemophilus influenzae type b
無脾症・脾摘後：脾臓がない、または機能が低下している患者（脾摘後、鎌状赤血球症など）では、肺炎球菌などによる脾摘後重症感染症（OPSI）のリスクが生涯にわたって高くなります。リスクは脾摘後1年以内、特に5歳未満で最も高くなります。予防として、ワクチン接種（肺炎球菌・髄膜炎菌・Hib）と、抗菌薬の予防投与を行います。

CHECK 9脾摘後重症感染症（OPSI）の原因として、最も代表的な細菌は？

正解：肺炎球菌。莢膜をもつ菌は、脾臓による血中からの除去に依存します。髄膜炎菌やHibも要注意です。
