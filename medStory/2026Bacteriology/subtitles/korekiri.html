BACTERIOLOGY BASICS

細菌学の基本、
まずはこれだけ。

細菌とは何か、グラム染色、球菌と桿菌、属と種、グラム染色以外の分類。細菌学各論に入る前に、最低限ここだけ押さえておきましょう。

POINT

この章の考え方

臨床的に問題となりうる細菌は、100種類を優に超えます。全部を一度に覚える必要はありません。まずは分け方を知ること。「どの引き出しに入る菌か」がわかれば、あとは中身を足していくだけです。

① 細菌とは→② グラム染色で2つに分ける→③ 形（球・桿）と配列で分ける→④ 染まらない仲間を別枠で
グラム染色の色を覚える語呂は、語呂合わせ・オヤジギャグ特集にあります。
WHAT IS A BACTERIUM

細菌とは：原核細胞

細菌（原核細胞）ヒトの細胞（真核細胞）
核膜ないある
細胞内小器官ないある（ミトコンドリアなど）
染色体細胞質全体に浮かんでいる核の中
細胞壁細胞膜の外にある（ただし一部例外あり）ない
最大の相違：核膜と細胞内小器官がないことが、真核細胞との最大の違いです。

📏 大きさ

一般的な細菌は、1μm〜数μm。単細胞ですが、それだけで一つの生物として成り立ちます。

🔬 見るには

観察には顕微鏡が必要です。しかも細菌は無色透明なので、色を付けて見ます。その代表的な方法が、グラム染色です。

CHECK 1細菌（原核細胞）と真核細胞の、最大の相違は？

正解：核膜や細胞内小器官がないこと。細胞壁は細菌の特徴ですが、一部に例外もあり、「最大の相違」ではありません。
GRAM STAIN

グラム染色：細菌を2つに分ける

グラム染色では、青（紫）に染まると陽性、赤に染まると陰性です。違いは、細胞壁の構造を反映しています。

※模式図です。実際の厚さの比率ではありません。

グラム陽性菌グラム陰性菌
染まる色青（紫）赤（ピンク）
細胞壁厚い（ペプチドグリカン層が厚い）薄い（ペプチドグリカン層が薄い）
外膜持たない持つ

🍬 莢膜

菌体の外側を覆う、水飴のようなトロッとした膜。

⚠️ 例外もある

多くの細菌はグラム染色で分類できますが、いくつか例外があります（染まりにくい菌は、あとの「ほかの分類」で）。

CHECK 2グラム陽性菌の細胞壁の特徴は？

正解：厚く、外膜を持たない。グラム陰性菌が、薄い細胞壁と外膜を持ちます。

CHECK 3「水飴のようなトロッとした膜」として説明される構造は？

正解：莢膜。菌体の外側を覆う膜です。
SHAPE AND ARRANGEMENT

形で分ける：球菌と桿菌

グラム染色（陽性／陰性）と、形（球菌／桿菌）をかけあわせると、4つのグループになります。

🔵 GPC　グラム陽性球菌

肺炎球菌、連鎖球菌、腸球菌、黄色ブドウ球菌

連鎖状（Chain）か、ブドウの房状（Cluster）かの相違が重要。

🔴 GNR　グラム陰性桿菌　最も多い

インフルエンザ菌、大腸菌、緑膿菌

🔴 GNC　グラム陰性球菌

淋菌、髄膜炎菌、モラクセラ

🔵 GPR　グラム陽性桿菌

コリネバクテリウム、リステリア、バチルス、クロストリジウム

バチルスとクロストリジウムは芽胞形成菌。

学習の優先順位：GPC・GNR ＞ GNC・GPR。よく出会う GPC と GNR から、深く学びます。グラム陰性桿菌は、最も種類が多いグループです。

球菌の並び方：Chain と Cluster

※模式図です。肺炎球菌は、2つずつ（双球菌）の連鎖として見られることがあります。

CHECK 4ブドウの房状（Cluster）に配列する代表的な菌は？

正解：黄色ブドウ球菌。連鎖状（Chain）なのは連鎖球菌などです。

CHECK 5最も種類が多く、代表に大腸菌・緑膿菌・インフルエンザ菌があるグループは？

正解：GNR。GPCと並んで、学習の優先順位が高いグループです。

CHECK 6グラム陰性球菌（GNC）の代表の組み合わせは？

正解：淋菌、髄膜炎菌、モラクセラ。1番目はグラム陽性桿菌、3番目はグラム陽性球菌です。

CHECK 7グラム陽性桿菌のうち、芽胞を形成する2つの菌は？

正解：バチルスとクロストリジウム。芽胞は、過酷な環境に耐える構造です。
TAXONOMY

どこまで知るか：目・科・属・種

菌は通常、属と種が重要です。ただし、菌によって、必要な深さが違います。

必要な深さ例
種まで知っておくべきものStaphylococcus aureus（黄色ブドウ球菌）と S. epidermidis（表皮ブドウ球菌）は、同じブドウ球菌属でも別の菌として扱う（補足）
属まででよいもの一覧で「spp.」と書かれているもの（Peptococcus spp.、Peptostreptococcus spp.、Actinomyces spp.、Nocardia spp.、Streptomyces spp.）
科・目まででよいものさらに上の分類で扱うものもある（補足：たとえば、腸内細菌目 Enterobacterales）
「spp.」は、その属の複数の種をまとめて示す表記です（補足）。

学名の書き方

  • 学名は、属名＋種名の二名法。属名は大文字で始まり、種名は小文字で始まります。イタリック体で書きます。例：Escherichia coli（エシェリキア属のコリ種）
  • 血清型（serovar）は、イタリック体にしません。Salmonella Typhi のように、大文字で始めます。
  • 正式には、Salmonella enterica subsp. enterica serovar Typhi。略して Salmonella Typhi と書きます。

CHECK 8チフス菌の、正しい略記は？

正解：2番目。Typhi は血清型なので、イタリックにせず、大文字で始めます。

CHECK 9菌名の一覧で「Nocardia spp.」と書かれている場合、どこまで知っておけばよい？

正解：属まで。spp. は、その属の複数の種をまとめた表記です。
OTHER GROUPS

グラム染色“以外”で分類されるもの

グラム染色では通常判別しない（しにくい）菌は、別の枠で覚えます。

グループ代表ひとこと（補足）
嫌気性菌バクテロイデス、フソバクテリウムなど酸素のない環境で増える。酸素の有無という別の軸の分類
抗酸菌結核菌（Mycobacterium tuberculosis）、MAC（M. avium、M. intracellulare）、らい菌（M. leprae）細胞壁に脂質が多く、特殊な染色（抗酸菌染色）を使う
スピリルムカンピロバクター（Campylobacter jejuni/coli）、ピロリ菌（Helicobacter pylori）らせん状の菌
スピロヘータ梅毒トレポネマ（Treponema pallidum）、レプトスピラ（Leptospira interrogans）、ボレリア（Borrelia）らせん状で、運動する菌
非定型菌マイコプラズマ（Mycoplasma pneumoniae）、レジオネラ（Legionella pneumophila）、リケッチア、クラミジアマイコプラズマは細胞壁を持たない。リケッチアやクラミジアは、細胞内でしか増えない
最初の「細胞壁がある（一部例外あり）」の例外：その代表が、細胞壁を持たないマイコプラズマです（補足）。細胞壁を標的にする抗菌薬（β-ラクタム系）が効かない理由にもなります。

CHECK 10結核菌、MAC、らい菌が属するグループは？

正解：抗酸菌。特殊な染色が必要な菌のグループです。

CHECK 11梅毒トレポネマ、レプトスピラ、ボレリアが属するグループは？

正解：スピロヘータ。カンピロバクターとピロリ菌は、スピリルムです。

CHECK 12マイコプラズマ、レジオネラ、リケッチア、クラミジアが属するグループは？

正解：非定型菌。典型的な細菌とは異なる性質を持つ菌のグループです。
FUNGI

真菌は3つ（と、特殊なもの）で考える

グループ代表
酵母様真菌Candida albicans、Cryptococcus neoformans、Trichosporon asahii
糸状菌Aspergillus fumigatus、Rhizopus oryzae
二形性真菌Coccidioides immitis、Histoplasma capsulatum、Paracoccidioides brasiliensis、Blastomyces dermatitidis、Talaromyces（Penicillium）marneffei
特殊な真菌Pneumocystis jirovecii

CHECK 13アスペルギルスとムコール目の Rhizopus が属する真菌のグループは？

正解：糸状菌。酵母様真菌の代表は、Candida や Cryptococcus です。
GLOSSARY

用語集・菌名の和名と学名

用語と、和名のある主要な菌の対応表です。和名のある主要な菌は、国家試験でも頻出なので、学名と対応できるようにしておきましょう。検索ボックスで絞り込めます。

📘 用語

原核細胞prokaryotic cell
核膜や細胞内小器官を持たない細胞。細菌がこれにあたる。染色体は細胞質全体に浮かんでいる。
真核細胞eukaryotic cell
核膜と細胞内小器官を持つ細胞。ヒトの細胞など。
細胞壁cell wall
細胞膜の外側にある構造。細菌の多くが持つが、一部例外（マイコプラズマなど）がある。
ペプチドグリカンpeptidoglycan
細菌の細胞壁をつくる成分。グラム陽性菌では厚く、グラム陰性菌では薄い。
外膜outer membrane
グラム陰性菌が持つ、細胞壁の外側の膜。グラム陽性菌は持たない。
莢膜capsule
菌体の外側を覆う、水飴のようなトロッとした膜。
芽胞spore
過酷な環境に耐える構造。バチルスとクロストリジウムが形成する。
グラム染色Gram stain
細菌を、青（紫）に染まる陽性と、赤に染まる陰性に分ける染色法。細胞壁の構造の違いを反映する。
球菌・桿菌coccus / bacillus (rod)
菌の形。丸いものを球菌、棒状のものを桿菌という。
GPC／GNR／GNC／GPRgram-positive cocci / gram-negative rods / gram-negative cocci / gram-positive rods
グラム陽性球菌／グラム陰性桿菌／グラム陰性球菌／グラム陽性桿菌。学習の優先順位は、GPC・GNR ＞ GNC・GPR。
連鎖状・房状chain / cluster
球菌の配列。連鎖球菌は連鎖状（Chain）、ブドウ球菌はブドウの房状（Cluster）。
二名法binomial nomenclature
属名＋種名で学名を表す方法。属名は大文字、種名は小文字で始め、イタリック体で書く。
血清型（serovar）serovar
種の下位の分類。イタリック体にせず、大文字で始める。Salmonella Typhi など。
spp.species (plural)
その属の複数の種をまとめて示す表記（補足）。「属まで」でよい菌に使われる。
嫌気性菌anaerobes
酸素のない環境で増える菌。バクテロイデス、フソバクテリウムなど。
抗酸菌acid-fast bacteria
結核菌、MAC、らい菌。細胞壁に脂質が多く、特殊な染色が必要（補足）。
スピリルムspirillum
らせん状の菌。カンピロバクター、ピロリ菌。
スピロヘータspirochete
梅毒トレポネマ、レプトスピラ、ボレリア。
非定型菌atypical bacteria
マイコプラズマ、レジオネラ、リケッチア、クラミジア。
酵母様真菌・糸状菌・二形性真菌yeast-like / filamentous / dimorphic fungi
真菌の3つの分類。
