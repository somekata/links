アクセスカウンター試作ページ

GitHub Pages上で動く無料のアクセスカウンターサービス「hits.sh」を使った試作ページです。 サーバーサイドの処理やJavaScriptなしで、画像バッジ（SVG）を埋め込むだけでカウントできます。

使い方メモ
  • 上の <img> タグの USERNAME.github.io/test/index の部分を、実際に公開するGitHub PagesのURLパスに書き換えてください（他と被らなければ何でもOKです。実在するURLである必要はありません）。
  • ページが読み込まれる（画像が表示される）たびにカウントが1つ増えます。
  • スタイルは style=flat-square のほか plastic / flat なども選べます。色は color= で16進カラーコード指定可能です。
  • 本番運用する場合は、リロード連打で数値が水増しされる点に注意してください（簡易カウンターのため厳密な集計には不向きです）。
